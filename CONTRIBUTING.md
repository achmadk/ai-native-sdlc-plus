# CONTRIBUTING

## Skill-quality checklist (all must hold)

- SKILL.md under 250 lines; detail in references/, templates in assets/.
- States what it does and when to use it with concrete trigger phrases.
- Produces a usable artifact today (spec, brief, review note, trace, policy, score).
- Adds no ceremony without evidence: lane-appropriate by default.
- Claims tagged [report-stated] / [measured here] / [extrapolated].
- Task evals + trigger evals run with negatives published; pass criteria pre-registered.
- Stdlib-only scripts, no network, no vendored binaries; tests for every script.
